七、PyTorch可视化

7.1 可视化网络结构

7.1.1 神经网络可视化背景

前面说过，要想基于某个开源神经网络进行二开，修改成符合自己需求的神经网络，需要对原开源神经的结构、输入输出有熟悉的了解。

直接使用Python原生的print函数打印相关神经网络实例，固然可以输出其结构，但只能得到其最粗略的构件信息（每一个模型块或层由哪些模型块组成，及构造函数的关键参数），不能直观地查看每一个模型块或层的输出形状、参数量、整个神经网络的参数量、前向反向传播参数量等统计信息。

此外，虽然可以直接查看其源码实现来实现上述目的，但阅读源码方式耗时长、不够直观。其实如果不需要关注具体实现的前提下，只是想快速、直观了解某开源神经网络的上述信息，可以直接使用开源社区已经提供的torchinfo等模块。

7.1.2 当前主流的神经网络结构可视化“工具栈”

在实际开发中，大家通常会结合不同的场景搭配不同的工具：

需求场景 推荐工具 特点
终端/Notebook 打印结构、张量 Shapes、计算显存 torchinfo (首选) 纯文本表格，无系统依赖，信息最全面
交互式 UI 拖拽、查看完整节点计算图、导出图片 Netron 桌面端/Web 软件，支持将 .pth / .onnx 转换为漂亮的计算流程图
训练过程中的计算图轨迹记录 TensorBoard / WandB 记录模型的算子连接关系及标量/图像指标
论文/报告中绘制高质量的网络架构矢量图 PlotNeuralNet / DrawIO 专门用于绘制漂亮、符合学术规范的 3D/2D 神经网络结构框图

如果你需要快速检查模型的层级结构、输入输出 Tensor 维度变换（Shapes matching）以及参数量和显存占用，torchinfo 仍然是当下 PyTorch 开发者的首选工具。

7.2 CNN可视化

卷积层是神经网络中非常重要的层，根据前面的学习，可以知道它的作用是提取输入数据的各种特征信息的。其被广泛地应用于图像处理领域，提升了神经网络处理问题的准确性和效率，促进了计算机视觉技术的发展与应用。

前面只是学习如何使用它即在模型中添加一个或多个卷积层，执行前向传播、反向传播不断更新优化它，就可以达到上述目的。但其是如何工作的、为什么能提取数据的各类特征？这也是我在学习中时常在思考的问题。就是说到目前为止，我们只是把它当成黑盒子来用，输入数据、得到结果，黑盒子中发生了什么不知道，这就涉及到卷积层的可解释性问题。

解决了卷积层的可解释性问题，我们可以从数理与逻辑分析角度解释其原理与工作过程，提升模型的稳定性与鲁棒性，进一步推动与控制其向更优化的方向前进。

到目前为止，确实有一些解决方案尝试或已经解决此问题，此处介绍主要是CNN的可视化这类方案。通过这类技术方案，我们可以知道CNN中卷积核关注哪些特征？特征图具体提到哪些特征？

本节学习的内容包括：卷积核的可视化、特征图的可视化、基于CAM的CNN可视化、基于FlashTorch的CNN可视化。

7.2.1 CNN卷积核可视化

7.2.1.1 卷积核可视化介绍

神经网络中，卷积层是用来提取数据特征的。如果将卷积核以 “蓝-白-红” 伪彩色热力图的形式绘制出来，可以以直接的形式来知道卷积核在关注哪些特征，进一步了解模型的关注重点与工作原理。

还需要特别注意颜色的含义。当前代码的 plt.imshow(filer.detach(), cmap='bwr') 没有指定统一的 vmin、vmax 或以 0 为中心的颜色归一化方式。Matplotlib 会对每一个小图单独按照它自己的最小值、最大值映射颜色。因此，在当前画法下：

  • 红色可靠表示“这个小图内部相对较大的权重”；
  • 蓝色可靠表示“这个小图内部相对较小的权重”；
  • 白色大致表示“该小图自身数值范围的中间位置”；
  • 但红色不一定严格表示正数、蓝色不一定严格表示负数，白色也不一定严格等于 0；
  • 不同小图的颜色深浅不能直接用于比较它们的权重绝对值大小。

7.2.2 CNN特征图可视化

7.2.2.1 特征图可视化介绍

卷积核可视化，是直接查看卷积层中已经学习好的权重；特征图可视化则是把某一张具体图片输入模型后，查看它经过某一层时实际得到的输出结果。也就是说，前者主要看“模型学到了什么样的局部加权规则”，后者主要看“这张图片经过模型后，哪些特征被激活了”。

对于图像 CNN，某一层输出的特征图通常是一个形状为 (N, C, H, W) 的张量。其中 N 是一次输入的图片数量，C 是输出通道数，H、W 是每张二维特征图的高和宽。若一次只输入一张图片，则 N=1；此时取出第 0 张图片后，会得到形状为 (C, H, W) 的张量，也就是 C 张不同的二维特征图。特征图可视化，就是将这些二维矩阵逐张绘制成灰度图或伪彩色图。

特征图中较亮或颜色较明显的位置，表示该通道在这些空间位置的激活相对更强；较暗的位置则表示该通道的激活相对较弱。通过观察不同通道的图像，可以大致了解这一层对图片中的哪些局部模式有响应。一般情况下，靠近输入的层更容易响应边缘、方向、纹理等简单结构；更深的层会在前面层提取到的特征基础上，组合出更复杂的模式。

不过，特征图只是网络的中间计算结果。看到某个通道在某处激活较强，并不能直接说明模型最终预测某个类别时“只关注了这里”，因为后面的卷积层、池化层和分类器还会继续处理、组合这些特征。若想进一步查看模型为了预测某个具体类别主要依赖原图的哪些区域，需要使用后面的 CAM、Grad-CAM 等方法。

Matthew D. Zeiler 和 Rob Fergus 在 2013 年的论文 Visualizing and Understanding Convolutional Networks 中，使用反卷积网络（Deconvolutional Network）等方法观察 CNN 中间层的激活情况。这样的可视化为理解 CNN 的中间表示提供了直观的经验工具，也帮助研究者改进了当时的网络结构（ZFNet）；但它是辅助理解模型的方式，不是对模型全部决策过程的数学证明。

7.2.3 CNN的CAM可视化及其衍进

7.2.3.1 CAM 的介绍

7.2.3.1.1 CAM的作用

Class Activation Mapping（CAM，类激活映射） 是一种用于深度学习模型（特别是卷积神经网络 CNN）“可解释性”的可视化技术。由Bolei Zhou等在2016年的论文 Learning Deep Features for Discriminative Localization 中提出。

简单来说，它就像是一张神经网络的“注意力热力图”：当模型把一张图片分类为“狗”时，CAM 能够以热力图的形式直接叠加在原图上，精准标示出模型究竟是看到了图片的哪个局部区域（比如狗的头部或耳朵），才做出了这个分类决定。即以醒目地方式标示出对预测结果最重要的区域。

7.2.3.1.2 CAM的工作原理

CAM 集中用于分类模型的CNN可视化。CAM 算法要求网络倒数第二层必须是“全局平均池化（GAP）”，且最后一层必须是全连接层。将模型最后一个卷积层输出的多个特征图（Feature Maps），按照它们对特定类别贡献的大小，进行“加权求和”。即将模型最后一个卷积层输出的多个特征图按照对应的权重乘起来并叠加在一起，最终得到一张反映“具体某分类结果比如猫”这个类别激活程度的高亮区域图。

打个比方： 假设最后一个卷积层输出了 512 个特征图：

  • 第 1 个特征图可能抓取到了“毛发纹理”；
  • 第 2 个特征图可能抓取到了“圆形的眼睛”；
  • 第 3 个特征图可能抓取到了“尖尖的耳朵”。

当模型识别“猫”这个类别时，全连接层的权重会告诉我们：“耳朵”和“眼睛”的特征图最重要（权重高），而“背景”特征图不重要（权重接近 0）。 CAM 就是把这 512 张特征图按照对应的权重乘起来并叠加在一起，最终得到一张反映“猫”这个类别激活程度的高亮区域图。

7.2.3.1.3 CAM 热力图如何解读？

生成的 CAM 图通常以伪彩色（Colormap，如 Jet 或 Rainbow）叠加在原图上：

  • 红色 / 暖色区域：高激活区。代表模型做决策时最关注、贡献最大的核心特征位置（例如猫的脸部）。
  • 蓝色 / 寒色区域：低激活区。代表模型认为与该类别无关或贡献极小的区域（例如背景墙面）。
7.2.3.1.4 CAM安装与示例

参考此开源项目的github仓库地址：https://github.com/zhoubolei/CAM。

由于CAM 算法要求网络倒数第二层必须是“全局平均池化（GAP）”，且最后一层必须是全连接层。就说是此算法对模型网络结构上面有非常严苛的限制，可以说这是它的一个“死穴”，导致通用性较差，学术界后续演化出了更强大的工具族。

此项目已经5年未更新，不推荐使用。但此CAM作为开山之作，首次给出了“直接的经验实证（Empirical Proof）”，即通过“眼见为实”的直接可视化解释了卷积层在干什么、是怎么工作的（在这之前，人们已经感知到“低层提取简单结构（线条/边缘），高层提取复杂实体形状”，也通过“理论推导与间接证明” 验证这一点，但仅仅局限于抽象层面），仍具有重要意义。

7.2.3.2 Grad-CAM 的介绍（推荐）

Grad-CAM 是CAM的演进版本。 ##### 7.2.3.2.1 为什么提出Grad-CAM

由于CAM存在以下致命缺陷：CAM 破坏了模型结构，且适用范围极窄

  • 必须包含全局平均池化（GAP, Global Average Pooling）：CAM 算法的公式推导严重依赖于网络倒数第二层必须是 GAP 层，且最后一层必须是全连接层（FC Layer）。
  • 模型需要重构甚至重新训练：如果原模型（如早期的 VGG、AlexNet、甚至包含多层全连接层的自定义网络）没有 GAP 层，或者全连接层不止一层，CAM 就完全无法直接使用。你必须修改网络结构（删掉 FC 层、加上 GAP），然后再重新训练模型，这对于已上线或结构复杂的模型来说成本极高。
  • 无法用于非分类任务：CAM 依赖类别 score 对 GAP 后的特征图权重的显式映射，因此很难直接应用于图像描述（Image Captioning）、视觉问答（VQA）、目标检测等复杂的多模态/复合任务。

为此Ramprasaath R. Selvaraju 等人提出了Grad-CAM （2017年的论文 Visual Explanations from Deep Networks via Gradient-based Localization 中提出）。

Grad-CAM 实现了如下突破性改进：

  • 结构零侵入（Model-Agnostic）：完全不需要修改现有网络结构，也不需要重新训练。无论是 ResNet、VGG、DenseNet 还是目标检测网络，只要是基于 CNN 的模型，拿来就能直接用。
  • 适用任意任务：只要网络是可导的，无论输出是分类得分、生成的文本词汇、还是目标的检测框坐标，都可以通过求导生成热力图。 如需了解其实现细节，继续深入阅读原论文。

CAM与Grad-CAM的精简对比总结如下：

特性 CAM (CVPR 2016) Grad-CAM (ICCV 2017)
网络结构要求 极严（必须带有 GAP + 单层 FC） 毫无限制（适用于任意 CNN 架构）
是否需要改动/重训网络 是（若无 GAP 则需修改并重新训练） 否（即插即用）
权重的获取方式 直接读取 FC 层的参数矩阵权重 通过反向传播计算梯度（Gradient）
适用任务范围 仅限图像分类 分类、目标检测、VQA、图像描述等
历史地位 开启了基于特征图加权的热力图先河 成为深度学习可解释性（XAI）的通用基准算法
7.2.3.2.2 grad-cam 的工作原理

Grad-CAM 的名称可以拆开理解：Grad 是 Gradient（梯度），CAM 是 Class Activation Mapping（类激活映射）。它不再像原始 CAM 那样直接读取“全连接层中已经存在的类别权重”，而是反过来问模型：

如果希望“猫”这个类别的得分更高，最后一个卷积层的哪些特征图、哪些位置最需要发生变化？

这个“需要怎样变化”的信息，就保存在梯度中。因此，Grad-CAM 的关键思想可以概括为：用目标类别得分对最后一个卷积层特征图的梯度，计算每个特征图对该类别的重要程度；再按重要程度把这些特征图加权合成一张热力图。

以“输入一张同时有猫和狗的图片，并解释模型为什么认为它是狗”为例，整个过程可以分为以下几步：

  1. 正常做一次前向传播，确定要解释的类别

    图片先经过卷积层、池化层和分类器，模型会给每个类别输出一个分数。假设本次关注的是“狗”类别，记它的分类分数为 \(y^c\)，其中 \(c\) 表示目标类别编号。

    这里通常使用分类器输出的原始分数（logit），而不是先经过 Softmax 得到的概率。可以简单理解为：Grad-CAM 要直接观察“让狗这一类得分变高”的依据。

  2. 取出一个较靠后的卷积层输出的特征图

    假设该卷积层一共输出 \(K\) 个通道，则可记为 \(A^1, A^2, \ldots, A^K\)。每个 \(A^k\) 都是一张二维特征图，图上的每个位置对应原图中的一个较大区域。

    和前面观察 CNN 特征图时一样，不同通道会对不同的图像模式产生响应。例如某些通道可能更容易响应于毛发、眼睛、轮廓或局部纹理。Grad-CAM 通常选择最后一个卷积层：它已经包含较高层的类别语义，同时仍保留“特征来自图片哪个位置”的二维空间信息。

  3. 从目标类别分数反向传播，计算梯度

    Grad-CAM 不训练模型，也不修改模型参数；它只针对本次输入，计算：

    \[ \frac{\partial y^c}{\partial A^k_{ij}} \]

    其中，\(A^k_{ij}\) 表示第 \(k\) 张特征图中第 \(i\) 行、第 \(j\) 列的一个数值。这个梯度可以通俗地理解为：若稍微增大该位置的激活值，目标类别“狗”的分数会受到多大影响。

    • 梯度为正且较大：该位置的激活增强通常会提高“狗”的得分；
    • 梯度接近 0：该位置对“狗”得分几乎没有影响；
    • 梯度为负：该位置的激活增强反而会降低“狗”的得分。

  4. 把每张特征图的梯度汇总为一个通道权重

    一张特征图上有许多位置，Grad-CAM 会对其梯度做全局平均池化（GAP），得到该通道对目标类别的总体重要性权重：

    \[ \alpha_k^c = \frac{1}{Z}\sum_i\sum_j \frac{\partial y^c}{\partial A^k_{ij}} \]

    其中，\(Z\) 是该特征图的空间位置总数。例如特征图大小为 \(14\times14\) 时，\(Z=196\)。\(\alpha_k^c\) 越大，说明第 \(k\) 个通道整体上越有助于提高“狗”这个目标类别的得分。

    这正是 Grad-CAM 相比 CAM 最重要的区别：CAM 使用分类器中固定存在的权重；Grad-CAM 每次都通过反向传播，根据当前图片、当前目标类别的梯度动态算出权重。

  5. 按权重叠加特征图，得到类别相关热力图

    有了每个通道的权重后，将所有特征图加权求和，并经过 ReLU：

    \[ L_{\mathrm{Grad\text{-}CAM}}^c = \operatorname{ReLU}\left(\sum_k \alpha_k^c A^k\right) \]

    ReLU 会将负值置为 0，因此最终热力图重点保留“对目标类别有正向支持作用”的区域，而不突出“会降低该类别得分”的区域。得到的 \(L_{\mathrm{Grad\text{-}CAM}}^c\) 就是一张较小的二维热力图。

  6. 放大并叠加回原图，便于人眼观察

    最后一个卷积层的特征图通常只有 \(7\times7\) 或 \(14\times14\)，而输入图片可能是 \(224\times224\)。因此需要先把热力图插值放大到输入图片大小，再使用伪彩色叠加到原图上。

    红色、黄色等暖色区域表示：在本次解释的目标类别下，该位置相对更有助于提高类别得分；蓝色等冷色区域表示相对贡献较小。这里的颜色表示同一张热力图内部的相对重要性，并不等价于“该像素属于目标物体的概率”，也不能把热力图当作精确的目标检测框或分割掩码。

7.2.3.2.3 当前使用的pytorch-grad-cam

由于原作者（首次提出Grad-CAM的作者）早期的代码多基于 Caffe 或旧版 Torch，目前在 Python/PyTorch 开发中，大家普遍使用的 Grad-CAM 官方标准开源库 是由 Jacob Gildenblat 维护的 pytorch-grad-cam（支持 CAM、Grad-CAM、Grad-CAM++、Eigen-CAM 等几乎所有衍生算法）。 即原作者提出的 Grad-CAM 算法（GitHub项目地址是：https://github.com/ramprs/grad-cam/）的“学术源头与开山官方实现”，pytorch-grad-cam（GitHub项目地址是：https://github.com/jacobgil/pytorch-grad-cam，）是开源社区基于前者思想推演、迭代并高度工程化封装后的“现代主流标准库”。

pytorch-grad-cam项目的官方文档网站：https://jacobgil.github.io/pytorch-gradcam-book/introduction.html。

学术界为了改进它的各种局限性，后来提出与实现了多个演进版本，形成了多个 CAM 算法家族衍生品，详见 CAM 算法家族衍生品 。

注：由于FlashTorch相关兼容性问题，要在 PyTorch 2.6.x 及以后版本中长期、可靠地实现显著性图或 Guided Backpropagation，建议使用原生 PyTorch 实现，或选择仍在维护的可解释性工具库（如前面介绍的 pytorch-grad-cam）。

7.2.4.1 FlashTorch 的介绍

MisaOgura/flashtorch 是一个专门针对 PyTorch 模型打造的神经网络特征可视化（Feature Visualization）与可解释性（XAI）轻量级 Python 工具包。

它的核心设计初衷是为了解决“神经网络黑盒化”以及“在 PyTorch 中从头编写可解释性可视化算法太繁琐”的问题。开发者只需几行代码，就可以直观地“看透”CNN 等模型内部到底关注了图像的哪些区域。

主要功能模块包括： 1. 显著性图 / 梯度可视化（flashtorch.saliency）

- **普通反向传播梯度图（Saliency Maps）**：计算预测类别相对于输入图像的梯度，高亮显示图像中对最终分类贡献最大的像素区域。
- **引导反向传播（Guided Backpropagation）**：通过在反向传播时过滤负梯度，绘制出像素级别的高分辨率细粒度纹理/轮廓。

  1. 激活极大化（flashtorch.activmax）

    • 激活最大化（Activation Maximization）：从随机噪声图像开始，通过梯度上升（Gradient Ascent）不断迭代更新输入像素，生成一张能够“最大程度激活指定神经元或卷积核（Filter）”的合成图像。这常用来观察网络不同深度（如浅层 Edge/Texture、高层 Object Concept）各自学会了什么概念。

  2. 数据与图像便捷处理（flashtorch.utils）

    • 内置针对 torchvision 预训练模型（如 AlexNet、VGG、ResNet 等）的图像预处理、ImageNet 类别索引查询（ImageNetIndex）以及可视化绘制工具。

7.2.4.2 与 pytorch-grad-cam 的定位区别

flashtorch与pytorch-grad-cam都能用于 CNN 可视化，但它们的侧重点和主要应用场景不一样。 主要区别如下：

维度 FlashTorch pytorch-grad-cam
侧重方向 梯度/显著性图（Saliency Maps） 与 激活极大化（Activation Maximization） 类激活映射图（CAM / Grad-CAM / Score-CAM 算法全家桶）
实现原理 侧重直接计算“像素级梯度”或合成“刺激神经元的最佳图案” 侧重在“最后一个卷积层”上进行特征图加权叠加
应用场景 适合分析细粒度线条/边缘/神经元偏好 适合定位目标主体的大致空间位置（粗粒度热力图）
