3.1 深度学习流程及与机器学习差异

一项机器学习任务的整体流程如下：

  • 数据准备与划分：对原始数据进行清洗、格式统一与特征变换，并划分为训练集、验证集和测试集（如采用随机切分或 K 折交叉，可以使用sklearn带的test_train_split函数、kfold来实现）。
  • 模型与算法配置：选择合适的网络架构，指定衡量误差的损失函数、更新参数的优化器以及相关超参数（可以使用sklearn这样的机器学习库中模型自带的损失函数和优化器）。
  • 模型训练（拟合）：将训练集输入模型，通过反向传播算法迭代更新权重以拟合数据。
  • 性能评估与调优：在验证集和测试集上评估模型的泛化能力，并根据表现进行超参数微调或最终效果验证。

深度学习与机器学习的差异如下：

对比维度 传统机器学习 深度学习
本质定义 数据驱动让程序从经验中提升性能，包含多种算法范式 机器学习的一个分支，特指用多层神经网络自动提取特征
特征提取方式 人工设计特征。依赖专家经验从原始数据中提取有用特征（如TF-IDF、HOG、SIFT等），特征的好坏直接影响模型上限 自动学习特征。网络底层自动学习边缘、纹理等低级特征，高层组合成语义特征，实现端到端学习，无需人工设计
数据需求量 较小。几百到几万样本即可取得不错效果，在小数据集上表现稳定，不易过拟合 较大。因参数量巨大，通常需要十万级以上样本才能充分训练，否则容易过拟合；可通过迁移学习/数据增强缓解
硬件依赖 CPU即可胜任。计算量相对较小，普通笔记本电脑即可运行大部分算法 重度依赖GPU。矩阵运算密集，需要GPU加速才能在大规模数据和深层网络上合理时间内完成训练
数据加载方式 通常可全量加载。数据量小，可一次性读入内存，训练过程简单直接 需mini-batch分批加载。数据量和模型参数量远超显存容量，必须分批次送入GPU训练，配合DataLoader、预读取等机制；批大小（batch size）本身也是影响模型收敛的重要超参数
模型构建方式 调用现成算法库。通常直接调用sklearn等库中的完整算法类，传入参数即可，无需逐层搭建网络结构 逐层搭建或模块组装。需手动定义网络各层（卷积层、池化层、批正则化层、LSTM层等），或预定义功能模块再组装，灵活性强但代码实现要求更高
损失函数与优化器 与深度学习类似，均需设定损失函数和优化器；但传统模型多为凸优化，调参相对简单 损失函数和优化器需保证反向传播能在用户自定义的复杂网络结构上正确实现；非凸优化对学习率、动量等超参数更敏感
GPU配置与操作 通常不需要。大部分传统ML算法在CPU上运行即可满足需求 必须显式管理。需将模型和数据手动“放到”GPU（.cuda()或.to(device)），损失函数和优化器也需在GPU上工作；多卡训练还需考虑模型并行/数据并行、梯度同步、结果汇总等问题；验证/评测时常需将数据“放回”CPU
训练与验证流程 全量数据一次性训练。通常一轮训练即可收敛（如线性回归闭式解），或少量迭代（如随机森林建树） 按批循环训练。每个epoch遍历所有batch，每批数据前向传播→计算损失→反向传播→优化器更新参数；需协调DataLoader、模型、损失函数、优化器、GPU之间的配合；验证时同样按批计算指标
可解释性 较强。树模型可直接输出特征重要性排序，线性模型系数有明确含义，易于理解和调试 较弱。黑盒特性显著，难以直观解释内部决策逻辑，需借助Grad-CAM、SHAP、注意力可视化等事后工具辅助理解
适用数据类型 结构化表格数据为主。在金融风控、电商推荐等表格数据场景中表现优异 非结构化数据为主。图像、语音、文本、视频等原始高维数据是深度学习的主场
表格数据表现 常胜。XGBoost、LightGBM等梯度提升树在表格数据上至今是工业界首选 未必占优。纯深度模型在表格数据上通常打不过调优后的GBDT，需结合TabNet等专门设计才有竞争力
图像/语音/NLP 基本退场。传统方法在这些领域已被深度学习全面超越 绝对主场。CNN统治图像，RNN/Transformer统治序列数据，大语言模型引领NLP前沿
典型算法举例 线性回归、逻辑回归、支持向量机(SVM)、决策树、随机森林、XGBoost、K近邻(KNN)、K均值聚类 卷积神经网络(CNN)、循环神经网络(RNN/LSTM)、Transformer、生成对抗网络(GAN)、扩散模型(Diffusion)、BERT/GPT

其中需要特别提到的是，深度学习所需的样本量一般更大，所以相关数据（训练集/验证集/测试集）一般无法一次性被加载到内存或显存中，此时一般分批输入数据。因此深度学习在数据加载上需要有专门的设计。

3.3 数据读入

此小节学习如下内容：PyTorch常见的数据读取方式、构建自己的数据读取流程。

在PyTorch中，通过Dataset与DataLoader的配合使用，完成对的数据集的加载与批量读入。其中Dataset告诉 PyTorch 数据在哪里、怎么读取某一条具体的数据（比如读取一张图片、一段文本或一行表格数据）、读取出来后要做什么预处理（数据变换/Augmentation），DataLoader本身就是一个可迭代对象（Iterable）、以迭代的方式不断按批次（就是一次读入固定的N个单数据，最后一个批次可能小于N个单数据）读入数据。

总结起来这二者的作用如下：

  • Dataset：解决“单条数据的提取与转换”问题（个体逻辑）。

  • DataLoader：解决“批量化、打乱、多线程加速与内存流式供给”问题（工程效率）。

不管处理的是图像、语音还是文本，DataLoader 的批处理逻辑是通用的，只需要编写对应数据类型的 Dataset 即可。PyTorch官方也提供了一些现成的具体Dataset类实现。

可以自定义类来实现灵活的数据读取，自定义类需要继承PyTorch自身的torch.utils.data.Dataset类。一般只需要重写几个核心方法：

  • __init__：初始化，传入外部参数、配置数据集运行所需的基础资源与参数。
  • __getitem__：用于逐个读取样本集合中的元素，可以进行一定的变换，并将返回训练/验证所需的数据。比如输入一个索引 idx，返回第 idx 条处理好的数据（比如：读取第 50 张图，裁剪放缩后，转换为 Tensor 并与标签一起返回）。
  • __len__：用于返回数据集的样本数。即告诉 PyTorch 一共有多少条数据（比如数据集一共 10000 张图）。

二维卷积层

虽然在深度学习中我们习惯叫“卷积”运算，但严格从数学定义上讲，神经网络里的卷积层实际上执行的是“互相关运算（Cross-correlation）”

  • 互相关运算：用一个较小的矩阵（卷积核 \(K\)）在较大的输入矩阵（输入 \(X\)）上从左到右、从上到下按步长滑动。每移动到一个位置，就将卷积核与输入对应的子区域按元素相乘再求和，得到输出矩阵 \(Y\) 中的一个点。
  • 标量偏差（Bias \(b\)）：一个可学习的标量，加到互相关运算结果的每一个元素上。
  • 参数更新：卷积核权重 \(W\) 和偏置 \(b\) 就是模型要学习的“参数”。它们初始时是随机给出的，在训练过程中通过反向传播（Backpropagation）和梯度下降逐步优化。

卷积层的模型参数包括了卷积核和标量偏差。在训练模型的时候，通常先对卷积核随机初始化，然后不断迭代更新卷积核和偏差。

卷积窗口形状为\(p×q\)的卷积层称为\(p×q\)卷积层。同样，\(p×q\)卷积或\(p×q\)卷积核说明卷积核的高和宽分别为p和q。一般情况下，p与q相等。

如果不手动指定初始化方法，PyTorch 会使用默认的 Kaiming 均匀分布（Kaiming Uniform Initialization） 来随机填充这个 \(p \times q\) 矩阵中的每个数值，每个元素有取值均匀分布在区间 \([-k, k]\) 内，其中 \(k = \frac{1}{\sqrt{\text{in\_channels} \times \text{p} \times \text{q}}}\)。

为了防止图像尺寸过快收缩（如果不加 Padding，每经过一层 \(3 \times 3\) 卷积，图像高宽就会减小 \(2\)。经过十几层卷积后，图像就会缩小为 \(1 \times 1\)，无法构建很深的网络结构。）、保护边缘信息（位于输入图像边缘和角落的像素点，如果不加 Padding，被卷积核扫描到的次数远远少于中心区域的像素；加了 Padding 之后，边缘像素也能被充分提取特征），我们在实际应用中会对输入数据上下左右加上填充（padding）。

填充的元素值一般都是 0，PyTorch 中 nn.Conv2d 的 padding 参数默认采用的就是 零填充。加上填充后，我们可以使输入数据与输出数据有相同高度、宽度。

还可以为卷积核窗口设置不同的高与宽。如果卷积核的高和宽不同时，可以通过在高和宽上设置不同的填充数，最后使得输出和输入具有相同的高和宽。

填充可以增加输出的高和宽。这常用来使输出与输入具有相同的高和宽。

做卷积过程中，卷积窗口在输入数据上按照从上到下、从左到右的规则滑动，每次滑动的行数或列数称为步幅（stride），行步幅与列步幅可以不同。

步幅可以减小输出的高和宽，例如将输出的高和宽变为指定的大小。

池化层

池化层每次对输入数据的一个固定形状窗口(⼜称池化窗口)中的元素计算输出。池化跟卷积操作顺序上有些类似，比如在二维池化中，池化窗口从输入数组的最左上方开始，按从左往右、从上往下的顺序，依次在输⼊数组上滑动计算池化窗口中满足计算规则的值。但此处的计算规则跟卷积中使用的计划规则不同，卷积中是计算卷积窗口中的输入与卷积核的互相关性，池化中是直接计算池化窗口中满足特定条件的元素值（如均值、最大值等）。

3.4.3.1 LeNet

上图是LeNet的网络结构，图来自杨立昆等著的论文《Gradient-based learning applied to document recognition》。

LeNet是一个简单的前馈神经网络，它接受一个输入，然后一层层不断向前传递，直到最后的输出。

一个神经网络的典型训练过程如下：

  • 定义包含可学习参数（如权重 Weight 和偏置 Bias）的神经网络
  • 在输入数据集上迭代
  • 通过网络处理输入
  • 计算 loss (输出和正确答案的距离）
  • 将梯度反向传播给网络的参数
  • 更新网络的参数（Parameters），一般使用简单的规则：\(\text{parameter} = \text{parameter} - \text{learning\_rate} \times \text{gradient}\)

  1. nn.Linear(256 * 5 * 5, 4096)：

    • 比起的 LeNet（120维），AlexNet 采用了巨大的隐层节点数（4096），极大地增强了模型的特征表达能力。
  2. nn.Dropout(0.5)：
    • 训练时以 50% 的概率随机断开神经元连接。
    • 作用：全连接层参数极多（如第一层全连接就有 \(6400 \times 4096 \approx 2600 万\) 个参数），极其容易过拟合。Dropout 是 AlexNet 能成功训练如此大网络的核心技术之一。
  3. nn.Linear(4096, 4096) \(\to\) nn.Linear(4096, 10)：
    • 再次经过 4096 维隐层后，最终输出 10 维分类logits（对应 Fashion-MNIST 的 10 个类别）。

3.5.2 torch.nn.init使用

在搭建或训练复杂的神经网络时，我们需要根据不同类型的网络层（如卷积层、全连接层、批归一化层等），为其选择最合适的权重初始化方法；而在代码实现中，我们通过 Python 的 isinstance() 函数来识别当前层到底属于哪种类型，从而精准地应用不同的 torch.nn.init 初始化策略。

3.5.2.1 为什么不同类型的层需要不同的初始化？

不同的网络层在数学逻辑和激活函数搭配上存在差异，混用同一种初始化方式会导致训练效果变差甚至无法收敛：

  • 卷积层（nn.Conv2d） & 全连接层（nn.Linear）：

    它们包含权重（weight）和偏置（bias）。如果后续接的是 ReLU 激活函数，通常建议使用 Kaiming (He) 初始化（如 nn.init.kaiming_normal_）；如果接的是 Tanh 或没有激活函数，通常建议使用 Xavier (Glorot) 初始化。

  • 批归一化层（nn.BatchNorm2d）：

    它的缩放参数 weight（即 \(\gamma\)）通常初始化为 1（保持方差不变），平移参数 bias（即 \(\beta\)）初始化为 0（保持均值不变），通常不能使用基于随机分布（如正态分布 normal_ 或均匀分布 uniform_）的初始化函数，而是直接使用 全 1 初始化 和 全 0 初始化。

  • 偏置项（bias）：

    不管是卷积层还是全连接层，偏置通常直接清零（nn.init.zeros_）。

3.6 损失函数

损失函数（loss function，也常称代价函数）用一个可微的数值衡量模型预测与目标之间的差异。训练时，模型先前向计算得到预测，再计算损失，随后调用 loss.backward() 自动求导；优化器据此更新模型参数，使训练集上的损失趋于减小。

本节以 PyTorch 2.6 的 API 为准。旧教程中的 size_average 与 reduce 已废弃，实际使用时统一通过 reduction 控制聚合方式：

  • reduction='mean'：默认值，返回所有损失元素的平均值；
  • reduction='sum'：返回所有损失元素之和；
  • reduction='none'：不聚合，保留每个样本（或元素）的损失，适合自行加权或排查异常样本。

选择损失函数时，首先要看任务和模型输出的含义：分类模型通常直接输出 logits（未经过 sigmoid 或 softmax 的实数）；回归模型输出连续数值；序列、排序和度量学习有各自专用的损失函数。

3.6.1 二分类：BCEWithLogitsLoss 与 BCELoss

二分类中每个样本只有“是/否”两种结果，标签通常为 0.0 或 1.0。BCEWithLogitsLoss 接收 logits，BCELoss 接收已经转换到 [0, 1] 的概率。新训练代码通常优先使用前者，以获得更好的数值稳定性。

BCEWithLogitsLoss

功能：计算二分类或多标签分类的二元交叉熵，并在内部完成 sigmoid，适合直接接收模型 logits。

主要参数：

  • weight：按元素或按样本缩放损失；
  • size_average：已废弃。旧代码中 True 表示平均、False 表示求和；请改用 reduction；
  • reduce：已废弃。旧代码中 False 表示不聚合；请改用 reduction='none'；
  • reduction：'none'、'mean' 或 'sum'；
  • pos_weight：按类别增加正样本权重，常用于正样本稀少的情况。

计算公式与说明：对一个元素，设 \(x\) 为 logits、\(y\in\{0,1\}\) 为目标、\(p=\sigma(x)\) 为预测为正类的概率，则：

\[ \ell(x,y)=-[y\log p+(1-y)\log(1-p)] \]

BCEWithLogitsLoss 在数值上以稳定方式直接由 \(x\) 计算上式，不需要先显式求 \(p\)。设置 pos_weight 后，正样本项会乘以该权重；批量损失再按 reduction 做逐元素保留、平均或求和。

代码逐行解释：

  1. logits = torch.tensor([...], requires_grad=True)：创建形状为 [4] 的浮点张量，可理解为一个批次中的 4 个样本各自输出 1 个二分类原始得分。它们不是概率，因此可以小于 0 或大于 1。requires_grad=True 会要求 Autograd 从此张量开始记录后续运算；在真实训练中，logits 通常来自模型最后一层，梯度会继续传回模型参数。
  2. targets = torch.tensor([1.0, 0.0, 1.0, 0.0])：创建与 logits 完全同形状的真实标签。BCE 系列要求标签是浮点张量而不是 long，1.0 表示正类、0.0 表示负类。形状不一致会导致错误或不符合预期的广播计算。
  3. nn.BCEWithLogitsLoss(...)：实例化损失函数。这里的 pos_weight=torch.tensor([2.0]) 表示发生正样本错误时，正类损失项按 2 倍计入；它适用于正样本比负样本少得多的场景。未显式传入 reduction，所以使用默认的 'mean'。
  4. ...(logits, targets)：调用损失模块完成前向传播。内部不会先暴露一个实际的 sigmoid 张量再计算对数，而是采用更稳定的等价公式直接从 logits 得到损失；因此模型最后一层不应再手动加 sigmoid。
  5. loss.backward()：loss 是一个标量，调用它会从损失节点沿计算图反向求导。此例的梯度保存在 logits.grad；真实训练循环通常接着调用 optimizer.step()，用这些梯度更新模型权重。
  6. print(...)：用 .item() 把单元素损失张量转换成普通 Python 浮点数，便于打印或记录。不要对非标量损失直接 backward()，除非提供对应的外部梯度。

内部计算过程：

示例数据：

  • logits = [1.2, -0.7, 0.3, -1.5]；
  • targets = [1, 0, 1, 0]；
  • pos_weight = 2，reduction='mean'。

计算步骤：

  1. 将 logits 转为概率（仅用于理解；实际函数内部以稳定方式完成）：

    \[p_i=\sigma(x_i)=\frac{1}{1+e^{-x_i}}\]

    \[p\approx[0.7685,\ 0.3318,\ 0.5744,\ 0.1824]\]

  2. 逐样本计算加权二元交叉熵：正类项乘以 pos_weight=2。

    \[l_i=-[2y_i\log(p_i)+(1-y_i)\log(1-p_i)]\]

    • \(l_1=-2\log(0.7685)\approx0.5266\)；
    • \(l_2=-\log(1-0.3318)\approx0.4032\)；
    • \(l_3=-2\log(0.5744)\approx1.1090\)；
    • \(l_4=-\log(1-0.1824)\approx0.2014\)。

  3. 得到最终输出：默认取平均值。

    \[loss=\frac{l_1+l_2+l_3+l_4}{4}\approx0.5601\]

梯度含义：未加权时梯度方向与 \(\sigma(x_i)-y_i\) 一致；正样本的梯度会被 pos_weight 放大，使模型更重视漏判的正样本。

BCELoss

功能：计算二分类的二元交叉熵。与 BCEWithLogitsLoss 不同，输入必须已经是范围在 [0, 1] 内的概率。

主要参数：

  • weight：为各损失元素设置手动缩放权重；
  • size_average：已废弃。旧代码中的平均/求和开关，应改为 reduction='mean' 或 'sum'；
  • reduce：已废弃。旧代码中关闭它相当于使用 reduction='none'；
  • reduction：指定不聚合、平均或求和。

计算公式与说明：公式与二元交叉熵相同： \[ \ell(p,y)=-[y\log p+(1-y)\log(1-p)] \]

此公式中取对数时的底数是自然数e。此处输入 \(p\) 已经是概率，必须满足 \(0\leq p\leq1\)；而 BCEWithLogitsLoss 的输入是 logits。两者的数学目标相同，区别主要在输入形式和数值稳定性。

代码逐行解释：

  1. logits = ... requires_grad=True：这 3 个值仍是模拟模型输出的原始得分。即使后面先经过 sigmoid，梯度链路仍会保留，因为 sigmoid 的输出依赖于 logits。
  2. probabilities = torch.sigmoid(logits)：逐元素应用 \(\sigma(x)=1/(1+e^{-x})\)，将任意实数映射到 (0,1)。这一步是 BCELoss 的前置条件；若误把 logits 直接传给 BCELoss，输入不一定是合法概率，训练结果会不正确。
  3. targets = ...：标签与 probabilities 同为 [3]，且必须是 0/1 浮点数。BCELoss 会将每个位置视作彼此独立的一次伯努利事件。
  4. loss = nn.BCELoss()(probabilities, targets)：先创建默认 reduction='mean' 的 BCELoss，再立即调用。它逐元素计算交叉熵，最后返回一个标量平均损失。
  5. loss.backward()：梯度先从平均损失传给 probabilities，再通过 sigmoid 的导数 \(p(1-p)\) 传回 logits。因此 logits.grad 可用，而 probabilities.grad 默认不保存，因为它不是叶子张量。
  6. print(...)：打印当前批次的平均交叉熵；训练中该数值可用于观察模型是否在学习，但不能单独代表准确率。

内部计算过程：

示例数据：

  • logits = [1.2, -0.7, 0.3]；
  • targets = [1, 0, 1]；
  • reduction='mean'。

计算步骤：

  1. Sigmoid 将 logits 转为 BCELoss 所需概率：

    \[p=\sigma(logits)\approx[0.7685,\ 0.3318,\ 0.5744]\]

  2. 逐样本计算交叉熵：

    \[l_i=-[y_i\log(p_i)+(1-y_i)\log(1-p_i)]\]

    • \(l_1=-\log(0.7685)\approx0.2633\)；
    • \(l_2=-\log(1-0.3318)\approx0.4032\)；
    • \(l_3=-\log(0.5744)\approx0.5544\)。

  3. 得到最终输出：

    \[loss=\frac{0.2633+0.4032+0.5544}{3}\approx0.4070\]

梯度含义：backward() 先计算损失对概率的导数，再乘 sigmoid 导数 \(p(1-p)\) 回传到 logits；预测正类概率不足时，梯度下降会增大对应 logits。

设：

\[ p=\sigma(x) \]

其中：

  • \(x\)：模型输出的 logits；
  • \(p\)：经过 sigmoid 后的预测为正类的概率；
  • \(y\in\{0,1\}\)：真实标签。

以单个样本为例，二元交叉熵损失为：

\[ \ell=-\left[y\ln p+(1-y)\ln(1-p)\right] \]

BCELoss 接收的是概率 \(p\)，所以反向传播先得到：

\[ \frac{\partial \ell}{\partial p} = \frac{p-y}{p(1-p)} \]

但模型真正需要更新的是产生 logits \(x\) 的网络参数，而不是概率 \(p\)。由于：

\[ p=\sigma(x) \]

且：

\[ \frac{\partial p}{\partial x}=p(1-p) \]

根据链式法则：

\[ \frac{\partial \ell}{\partial x} = \frac{\partial \ell}{\partial p} \frac{\partial p}{\partial x} = \frac{p-y}{p(1-p)}\cdot p(1-p) = p-y \]

如果损失按批量平均（默认 reduction='mean'），批量大小为 \(n\)，则：

\[ \frac{\partial L}{\partial x_i} = \frac{p_i-y_i}{n} \]

“预测正类概率不足时，梯度下降会增大对应 logits”的含义是：

  • 若真实标签 \(y=1\)，但预测概率 \(p=0.3\)，则：

    \[ p-y=0.3-1=-0.7 \]

    此时梯度为负。

  • 梯度下降的更新形式是：

    \[ x\leftarrow x-\eta\frac{\partial L}{\partial x} \]

    减去负数等于增加，所以 logits \(x\) 会变大。

  • sigmoid 是单调递增函数；\(x\) 变大后，\(p=\sigma(x)\) 也会变大，模型就更倾向预测正类。

反过来，若 \(y=0\) 但模型预测的 \(p\) 很大，则 \(p-y>0\)。梯度下降会减小 logits，使 sigmoid 输出的概率下降。

3.6.2 单标签多分类：CrossEntropyLoss

单标签多分类中，每个样本只属于一个类别。模型输出每个类别的 logits，目标是对应的类别索引。

CrossEntropyLoss

功能：计算单标签多分类交叉熵，内部等价于 LogSoftmax + NLLLoss。输入为 [N, C] 的 logits，目标通常为 [N] 的类别索引。

主要参数：

  • weight：长度为类别数 C 的权重，用于类别不平衡；
  • size_average：已废弃，请用 reduction；
  • ignore_index：忽略指定类别索引的损失，常用于序列填充；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式；
  • label_smoothing：标签平滑系数，默认 0.0。

计算公式与说明：设第 \(n\) 个样本的 logits 为 \(x_n\in\mathbb{R}^{C}\)，正确类别索引为 \(y_n\)，则无标签平滑时：

\[ \ell_n=-\log\frac{\exp(x_{n,y_n})}{\sum_{c=1}^{C}\exp(x_{n,c})} \]

它会提高正确类别的得分、压低其他类别的相对得分。label_smoothing>0 时，不再把全部目标概率放在正确类别上，而会向其他类别分配少量概率，从而减轻模型过度自信。

代码逐行解释：

  1. logits = torch.tensor([[...], ...], requires_grad=True)：创建形状 [3,4] 的张量：第 0 维是 3 个样本，第 1 维是 4 个类别。每行的值只是相对得分，不是概率，因此每行不要求和为 1。
  2. targets = torch.tensor([0, 1, 3], dtype=torch.long)：为每个样本保存一个正确类别的索引。CrossEntropyLoss 的类别索引目标必须是 long；这里不应传入 [1,0,0,0] 形式的 one-hot 向量。
  3. nn.CrossEntropyLoss(label_smoothing=0.1)：实例化交叉熵。默认 reduction='mean'；label_smoothing=0.1 让训练目标不再是绝对 one-hot，从而避免模型被过度鼓励给正确类输出概率 1。
  4. loss = criterion(logits, targets)：前向计算时，对每一行 logits 独立做 log_softmax，再取对应目标类别（或平滑后目标分布）的负对数似然；不需要、也不应该在此之前手工 softmax。
  5. loss.backward()：将 3 个样本平均后的标量损失反向传播。对每一行，正确类别的梯度倾向于使其得分上升，其他类别的梯度倾向于使其得分下降；标签平滑会减弱这个推动力度。
  6. argmax(dim=1)：若用于推理，取每行最大 logits 的索引即可得到预测类。由于 softmax 是单调变换，先 softmax 再 argmax 得到的索引相同。

内部计算过程：

示例数据：第一行 logits 为 [2.0, 0.1, -1.0, 0.3]，正确类别为 0；共有 \(C=4\) 类，label_smoothing=0.1。

计算步骤：

  1. 对第一行执行 softmax：

    \[p_c=\frac{e^{x_c}}{\sum_j e^{x_j}}\approx[0.7239,\ 0.1082,\ 0.0360,\ 0.1320]\]

  2. 构造平滑后的目标分布：

    \[q_0=1-0.1+\frac{0.1}{4}=0.925,\qquad q_1=q_2=q_3=\frac{0.1}{4}=0.025\]

  3. 计算该样本交叉熵：

    \[l_1=-\sum_{c=0}^{3}q_c\log p_c\]

    正确类 \(p_0\) 贡献最大，其他类的少量目标概率用于抑制过度自信。第二、三行分别使用标签 1、3 重复此过程。

  4. 得到最终输出：将三个样本损失按默认方式平均。

    \[loss=\frac{l_1+l_2+l_3}{3}\]

梯度含义：每类的梯度近似为 \((p_c-q_c)/3\)；正确类概率不足时提高正确类 logits，预测过高的错误类 logits 被压低。

3.6.3 回归：L1Loss、MSELoss 与 SmoothL1Loss

回归任务预测连续数值；三种损失函数的主要差异在于对大误差和异常值的惩罚方式。

L1Loss

功能：计算预测值和目标值的平均绝对误差（MAE），即 \(|x-y|\)，对异常值比 MSE 更不敏感。

主要参数：

  • size_average：已废弃。旧代码中控制平均或求和，请改用 reduction；
  • reduce：已废弃。旧代码中关闭聚合，请改用 reduction='none'；
  • reduction：逐元素返回、平均或求和。

计算公式与说明：对第 \(n\) 个元素：

\[ \ell_n=|x_n-y_n| \]

绝对值使得误差增大时损失线性增长，因此相比 MSE，个别很大的误差不会被额外平方放大。

代码逐行解释：

  1. prediction = ... requires_grad=True：创建 3 个连续预测值，形状为 [3]。在实际回归模型中它来自最后一层的输出，不需要 sigmoid 或 softmax。
  2. target = ...：给出每个预测位置对应的真实连续值，必须能与 prediction 一一对应；两者形状最好完全相同，避免无意的广播。
  3. nn.L1Loss(reduction='mean')：明确指定按平均值返回标量。若改为 'none'，会得到 [0.5,0.5,0] 这类逐元素损失，便于检查哪个样本误差最大。
  4. loss.backward()：将平均绝对误差对每个预测值求导。由于绝对值在零点不可导，PyTorch 在该点采用子梯度规则；学习时一般不影响使用。
  5. print(...)：打印平均 MAE，其单位与目标值相同，因而通常比 MSE 更直观。

内部计算过程：

示例数据：prediction = [2.5, 0.0, 2.0]，target = [3.0, -0.5, 2.0]，reduction='mean'。

计算步骤：

  1. 计算逐元素误差：

    \[d=prediction-target=[-0.5,\ 0.5,\ 0]\]

  2. 取绝对值得到逐元素 L1 损失：

    \[l=|d|=[0.5,\ 0.5,\ 0]\]

  3. 得到最终输出：

    \[loss=\frac{0.5+0.5+0}{3}=\frac{1}{3}\approx0.3333\]

梯度含义：三个 prediction 的梯度方向分别为 \([-1/3,1/3,0]\)（零点处取子梯度）。梯度下降会增加 2.5、降低 0.0，而第三项无需调整。

MSELoss

功能：计算均方误差（MSE），即 \((x-y)^2\)。大误差会被平方后放大，因此对离群点更敏感。

主要参数：

  • size_average：已废弃，请用 reduction 表示平均或求和；
  • reduce：已废弃，请用 reduction='none' 保留各元素损失；
  • reduction：逐元素返回、平均或求和。

计算公式与说明：对第 \(n\) 个元素：

\[ \ell_n=(x_n-y_n)^2 \]

平方会使大误差的贡献急剧变大；因此它会更积极地修正大误差，但也更容易受离群点影响。

代码逐行解释：

  1. prediction：三个回归预测中最后一个值为 8，特意设置成明显偏离目标，用于观察平方惩罚的效果；它是需要求梯度的叶子张量。
  2. target：对应真实值 [3.0,-0.5,3.0]，与预测值逐元素配对。
  3. nn.MSELoss()：默认 reduction='mean'。前向传播先计算每个位置的误差，再平方，最后将 3 个平方误差平均成一个标量。
  4. loss.backward()：计算 \(L\) 关于每个 prediction 的梯度并写入 prediction.grad。平方使远离目标的预测得到更强的梯度修正。
  5. print(...)：输出的 8.5 是均方误差，不是原始单位下的平均偏差；因此它通常比 MAE 更难直接解释。

内部计算过程：

示例数据：prediction = [2.5, 0.0, 8.0]，target = [3.0, -0.5, 3.0]，reduction='mean'。

计算步骤：

  1. 计算误差：

    \[d=[-0.5,\ 0.5,\ 5]\]

  2. 平方得到逐元素损失：

    \[l=d^2=[0.25,\ 0.25,\ 25]\]

  3. 得到最终输出：

    \[loss=\frac{0.25+0.25+25}{3}=8.5\]

梯度含义：

\[\frac{\partial loss}{\partial prediction_i}=\frac{2(prediction_i-target_i)}{3}\approx[-0.333,\ 0.333,\ 3.333]\]

第三项大误差的梯度远大于前两项，说明 MSE 会强烈惩罚离群误差。

SmoothL1Loss

功能：小误差区域使用平滑的二次函数，大误差区域近似 L1 损失，兼顾 MSE 的平滑性与 L1 对异常值的鲁棒性。

主要参数：

  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：逐元素返回、平均或求和；
  • beta：L1 与二次区域的分界阈值，默认 1.0。

计算公式与说明：令 \(d=x-y\)，则：

\[ \ell(d)= \begin{cases} \dfrac{0.5d^2}{\beta}, & |d|<\beta\\ |d|-0.5\beta, & |d|\geq\beta \end{cases} \]

误差较小时使用二次函数，梯度在零点附近更平滑；误差较大时使用线性增长，避免 MSE 对异常值的过度惩罚。

代码逐行解释：

  1. prediction 与 target：使用和 MSE 示例相同的数据，使三种回归损失的数值差异只来自损失函数本身。
  2. nn.SmoothL1Loss(beta=1.0)：创建 Huber 风格的平滑 L1 损失。beta 是从二次区域切换到线性区域的阈值，不是优化器的学习率。
  3. 前向调用：函数逐元素判断 \(|prediction-target|\) 是否小于 1，然后选用对应的分段公式；默认对所有元素平均。
  4. backward()：小误差区域的梯度随误差线性变化且在 0 处平滑；大误差区域的梯度幅度被限制，类似 L1，因此不会像 MSE 一样被异常值主导。
  5. print(...)：输出是三种分段损失的平均值，适合和 MSE/L1 对照。

内部计算过程：

示例数据：prediction = [2.5, 0.0, 8.0]，target = [3.0, -0.5, 3.0]，beta=1.0。

计算步骤：

  1. 计算误差：

    \[d=[-0.5,\ 0.5,\ 5]\]

  2. 按 \(|d|\) 与 beta 的关系选择分段公式：

    • 前两项 \(|d|=0.5<1\)，\(l=0.5d^2=0.125\)；
    • 第三项 \(|d|=5\ge1\)，\(l=|d|-0.5=4.5\)。

  3. 得到最终输出：

    \[loss=\frac{0.125+0.125+4.5}{3}\approx1.5833\]

梯度含义：小误差的梯度与误差成正比；第三项进入 L1 区域，平均后的梯度幅度只有 \(1/3\)，不会像 MSE 那样被大误差放大。

3.6.4 计数和概率分布：PoissonNLLLoss 与 KLDivLoss

这类损失分别用于非负计数建模，以及两个概率分布之间的匹配。

PoissonNLLLoss

功能：计算目标服从泊松分布时的负对数似然损失，适合预测非负计数，例如单位时间内的事件数量。

主要参数：

  • log_input：默认 True，表示输入是预测率的对数；此时模型可输出任意实数；
  • full：是否加入 Stirling 近似项以得到更完整的泊松负对数似然；
  • size_average：已废弃，请用 reduction；
  • eps：当 log_input=False 时用于避免计算 log(0)；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式。

计算公式与说明：设目标计数为 \(y\)。当 log_input=True 时，输入 \(x=\log\lambda\)，其中 \(\lambda\) 是泊松分布的预测率：

\[ \ell(x,y)=\exp(x)-yx \]

当 log_input=False 时，输入直接是 \(\lambda\)，公式为 \(\ell(\lambda,y)=\lambda-y\log(\lambda+\varepsilon)\)。full=True 还会加入与 \(\log(y!)\) 有关的近似项，使损失更接近完整负对数似然。

代码逐行解释：

  1. log_rate = ... requires_grad=True：三个值表示模型输出的 \(\log\lambda\)，不是直接的计数，也不是概率。这样模型可以输出任意实数，内部指数运算会保证预测率 \(\lambda\) 始终为正。
  2. counts = ...：真实观察计数为 [1,3,2]。虽然逻辑上是整数计数，PyTorch 损失计算时使用浮点张量以参与连续的自动求导。
  3. nn.PoissonNLLLoss(log_input=True, full=True)：log_input=True 告诉函数调用 \(\exp(log\_rate)\) 恢复率；full=True 加入关于阶乘项的近似，使不同计数的损失比较更接近完整的泊松负对数似然。默认仍按平均返回。
  4. loss.backward()：梯度会作用于 log_rate。若当前预测率低于实际计数，梯度下降会倾向增大 log-rate；反之则降低它。
  5. print(...)：输出为三个计数样本的平均负对数似然，而非“预测计数的平均误差”。

内部计算过程：

示例数据：log_rate = [0.0, 0.7, 1.2]，counts = [1,3,2]；log_input=True、full=True。

计算步骤：

  1. 恢复每个样本的泊松预测率：

    \[\lambda=e^{log\_rate}\approx[1.0000,\ 2.0138,\ 3.3201]\]

  2. 计算核心负对数似然项：

    \[l_i^{core}=\lambda_i-y_i\log\lambda_i=\lambda_i-y_i\cdot log\_rate_i\]

    得到 \([1.0000,\ -0.0862,\ 0.9201]\)。由于 full=True，对计数大于 1 的后两项还会加入 \(\log(y_i!)\) 的 Stirling 近似项。

  3. 得到最终输出：对完整的三个逐元素 NLL 按默认 mean 求平均。

梯度含义：核心梯度为 \(\lambda_i-y_i\)。第二项约为 \(-0.9862\)，梯度下降会增大其 log_rate，从而把预测率从 2.01 推向真实计数 3。

KLDivLoss

功能：计算两个概率分布之间的 KL 散度。默认时第一个输入是对数概率，第二个输入是普通概率，常用于知识蒸馏和分布匹配。

主要参数：

  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：可取 'none'、'sum'、'mean' 或 'batchmean'；常用 'batchmean'，与 KL 散度的标准批量定义一致；
  • log_target：为 False（默认）时 target 是普通概率；为 True 时 target 也必须是对数概率。

计算公式与说明：令目标分布为 \(P\)，模型分布为 \(Q\)，则：

\[ D_{\mathrm{KL}}(P\|Q)=\sum_i P(i)\log\frac{P(i)}{Q(i)} \]

默认 log_target=False 时，input 传入 \(\log Q(i)\)，target 传入 \(P(i)\)。KL 散度不对称，衡量的是“用 \(Q\) 近似 \(P\)”时的差异；batchmean 会先对每个样本求和，再除以批量大小。

代码逐行解释：

  1. student_logits：形状为 [2,3]，两行是两个样本，三列是类别得分。它模拟待训练模型的输出，因此设置 requires_grad=True。
  2. target_probs：也是 [2,3]，每行都是合法概率分布，必须非负且和为 1；它可以来自教师模型、软标签或人工设定的目标分布。
  3. F.log_softmax(student_logits, dim=1)：沿类别维计算对数 softmax，直接得到 \(\log Q\)。不能传普通 logits 给默认的 KLDivLoss，也不要传 softmax 后的普通概率作为 input。
  4. nn.KLDivLoss(reduction='batchmean')：默认 log_target=False，因此第二个参数被视为普通概率 \(P\)。batchmean 是把所有类别损失求和后只除以批量大小 2，而不是再除以类别数。
  5. backward()：让每行学生分布 \(Q\) 接近目标 \(P\)；目标分布默认不要求梯度，只有 student logits 会收到梯度。

内部计算过程：

示例数据：第一行学生 logits 为 [1.0,0.2,-0.5]，目标分布为 [0.7,0.2,0.1]；reduction='batchmean'。

计算步骤：

  1. 将 logits 归一化为学生分布：

    \[Q=softmax([1.0,0.2,-0.5])\approx[0.5979,\ 0.2687,\ 0.1334]\]

  2. 计算每个类别的 KL 项：

    \[t_i=P_i(\log P_i-\log Q_i)=P_i\log\frac{P_i}{Q_i}\]

    分别代入 \(P=[0.7,0.2,0.1]\) 后再求和，得到第一样本的 \(KL_1\)。

  3. 得到最终输出：第二行同样得到 \(KL_2\)，随后：

    \[loss=\frac{KL_1+KL_2}{2}\]

梯度含义：目标概率高于学生概率的类别会被提高 logits，反之被压低；KL 是有方向的 \(D_{KL}(P\|Q)\)，交换两者不会得到同一数值。

3.6.5 排序、边界与度量学习损失

这类损失约束样本之间的排序关系、类别间隔、距离或嵌入向量的相似度，而非直接进行常规单标签分类。

MarginRankingLoss

功能：比较两个输入得分的相对大小。目标为 1 时希望 input1 > input2，目标为 -1 时希望 input1 < input2，常用于排序任务。

主要参数：

  • margin：两个得分之间要求满足的最小间隔；
  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式。

计算公式与说明：设 \(y\in\{-1,1\}\)，则单个样本的损失为：

\[ \ell(x_1,x_2,y)=\max(0,-y(x_1-x_2)+\text{margin}) \]

当 \(y=1\) 时，只有在 \(x_1\) 没有比 \(x_2\) 至少大 margin 时才产生损失；当 \(y=-1\) 时，约束方向相反。

代码逐行解释：

  1. input1 与 input2：各有两个元素，索引相同的位置构成一对待排序得分；两者均开启梯度，以便观察违反约束时两个分数如何被同时调整。
  2. targets = [1.0,-1.0]：这是排序方向标签而不是类别编号。第一个 1 要求 \(input1[0]>input2[0]\)；第二个 -1 要求 $input1[1]<input2[1]`。
  3. MarginRankingLoss(margin=0.5)：要求满足方向还不够，两个得分的间隔至少为 0.5。默认将两个样本损失取平均。
  4. 前向与 backward()：函数逐位置计算 hinge 损失。只有某对未达到指定间隔时才产生梯度；已经正确且间隔足够的对不再被继续拉开。

内部计算过程：

示例数据：input1=[2.0,0.2]，input2=[1.0,0.8]，targets=[1,-1]，margin=0.5。

计算步骤：

  1. 第一对（目标为 1）：要求 \(input1-input2\ge0.5\)。

    \[l_1=\max(0,-1(2.0-1.0)+0.5)=0\]

  2. 第二对（目标为 -1）：要求 \(input2-input1\ge0.5\)。

    \[l_2=\max(0,-(-1)(0.2-0.8)+0.5)=0\]

  3. 得到最终输出：

    \[loss=(l_1+l_2)/2=0\]

梯度含义：两对都已满足间隔，因此梯度均为 0。若第一对的 input1 低于 1.5，就会产生正损失，并推动 input1 上升、input2 下降。

MultiLabelMarginLoss

功能：计算多标签分类的边界损失。目标中列出一个样本所属的多个类别索引，其余位置用 -1 填充。对于现代多标签分类通常更推荐 BCEWithLogitsLoss。

主要参数：

  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式。

计算公式与说明：对一个样本，设正标签集合为 \(Y\)，所有类别得分为 \(x_i\)，该损失对每个正标签 \(j\in Y\) 与每个非正标签 \(i\notin Y\) 计算：

\[ \ell=\frac{1}{C}\sum_{j\in Y}\sum_{i\notin Y}\max(0,1-x_j+x_i) \]

它要求每个正标签得分至少比非正标签高 1。目标张量用 -1 表示“正标签列表到此结束”。

代码逐行解释：

  1. scores：形状为 [1,4]，第一个维度表示一个样本，4 列是该样本对 4 个类别的分数。它不是 softmax 概率，各类别分数可以独立增减。
  2. targets：与 scores 同形状且类型为 long。前两个位置列出正标签类别 1、3；第一个 -1 表示标签列表结束，后面的值不再参与。
  3. MultiLabelMarginLoss()：对“每个正类 × 每个负类”计算间隔项，要求每个正类得分都至少高出负类 1；它默认对批量求平均。
  4. backward()：违反约束的正类会获得提升分数的梯度，相关负类会获得降低分数的梯度；已满足间隔的配对梯度为 0。

内部计算过程：

示例数据：scores=[0.2,0.8,0.1,0.9]；targets=[1,3,-1,-1]，所以正类为 1、3，非正类为 0、2。

计算步骤：

  1. 取出正、负类别得分：正类得分为 \(0.8,0.9\)，负类得分为 \(0.2,0.1\)。

  2. 计算所有正负配对的间隔项：

    \[\max(0,1-x_j+x_i)\]

    得到 \(0.4,0.3,0.3,0.2\)，分别对应正类 1/3 与负类 0/2 的 4 个组合。

  3. 得到最终输出：函数将这些正损失项按类别数进行内部归一化，再按默认方式聚合为单个样本损失。

梯度含义：每个正项都会提升对应正类得分并降低对应负类得分，直到所有正类至少比负类高 1。

SoftMarginLoss

功能：计算以 -1 和 1 为标签的逐元素二分类 logistic 损失。若数据集标签为 0/1，一般应使用 BCEWithLogitsLoss。

主要参数：

  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式。

计算公式与说明：标签 \(y\) 必须为 \(-1\) 或 \(1\)，单个元素损失为：

\[ \ell(x,y)=\log(1+\exp(-yx)) \]

当 \(y=1\) 时，增大 \(x\) 能减小损失；当 \(y=-1\) 时，减小 \(x\) 能减小损失。这与 BCEWithLogitsLoss 的标签编码不同。

代码逐行解释：

  1. scores：形状 [3] 的任意实数得分，分别代表三次独立二元判别的 raw score；不需要预先做 sigmoid。
  2. targets：必须和 scores 同形状，但标签编码是 \(+1/-1\)，这与 BCE 使用 \(1/0\) 的编码不同。
  3. nn.SoftMarginLoss()：内部把每一项写为 \(\log(1+e^{-yx})\) 并使用默认平均聚合；当 \(yx\) 越大，表示预测方向越正确且越自信，损失越小。
  4. backward()：对正标签推动分数向正无穷方向移动，对负标签推动分数向负无穷方向移动；梯度会随间隔变大而逐渐减小。

内部计算过程：

示例数据：scores=[0.8,-0.4,1.2]，targets=[1,-1,1]，默认 reduction='mean'。

计算步骤：

  1. 先计算分类方向乘积：

    \[y\cdot x=[0.8,\ 0.4,\ 1.2]\]

    第二项虽然 score 为负，但目标也是 -1，因此方向正确。

  2. 逐元素计算 logistic 损失：

    \[l_i=\log(1+e^{-y_ix_i})\approx[0.3711,\ 0.5130,\ 0.2633]\]

  3. 得到最终输出：

    \[loss=(0.3711+0.5130+0.2633)/3\approx0.3825\]

梯度含义：\(y_ix_i\) 越大，损失越接近 0；梯度下降会使正样本 score 变大、负样本 score 变小。

MultiMarginLoss

功能：计算单标签多分类的 hinge 损失。实际多分类任务中，CrossEntropyLoss 往往更常用。

主要参数：

  • p：间隔惩罚的指数，只能取 1 或 2；
  • margin：正确类别得分相对其他类别要求满足的最小间隔；
  • weight：按类别设置的权重；
  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式。

计算公式与说明：设正确类别为 \(y\)，类别数为 \(C\)，则：

\[ \ell(x,y)=\frac{1}{C}\sum_{i\ne y}\max(0,\text{margin}-x_y+x_i)^p \]

若正确类别得分 \(x_y\) 已比每个其他类别至少高 margin，对应项为 0；p 决定对违反间隔的惩罚是线性还是平方。

代码逐行解释：

  1. scores：形状 [2,3]，第一维是两个样本，第二维是三个类别的得分。每行可看作一个多分类模型的输出，但此处训练目标采用 hinge 间隔而非 softmax 交叉熵。
  2. targets：[1,0] 是两个正确类别索引，类型为 long。第一行要让第 1 类得分最高，第二行要让第 0 类得分最高。
  3. MultiMarginLoss(p=1, margin=1.0)：对正确类与每个错误类构造 \(\max(0,1-x_y+x_i)\)。p=1 是线性 hinge；若设为 2，违反间隔的项会被平方。
  4. 前向调用与 backward()：所有违反间隔的错误类都会推高损失。反向传播提升正确类得分，并降低发生违反的错误类得分；已经满足间隔的类别不产生梯度。

内部计算过程：

示例数据：两行 scores 为 [[0.2,1.0,0.1],[0.9,0.3,0.5]]，正确类别 targets=[1,0]，margin=1、p=1。

计算步骤：

  1. 第一样本，正确类为 1：

    \[\max(0,1-1.0+0.2)=0.2,\qquad\max(0,1-1.0+0.1)=0.1\]

  2. 第二样本，正确类为 0：

    \[\max(0,1-0.9+0.3)=0.4,\qquad\max(0,1-0.9+0.5)=0.6\]

  3. 得到最终输出：函数将每行错误类别对应的项按类别数归一化，再对两个样本按默认 mean 聚合。

梯度含义：4 个项都违反间隔，因此各正确类 logits 会被提高，4 个对应错误类 logits 会被压低。

TripletMarginLoss

功能：计算三元组损失。它让锚点 anchor 与同类样本 positive 的距离，小于锚点与异类样本 negative 的距离，并至少相差一个 margin。

主要参数：

  • margin：正负样本距离之间要求的最小间隔；
  • p：距离使用的 \(p\) 范数，默认 2.0 即欧氏距离；
  • eps：数值稳定项；
  • swap：为 True 时，额外比较正样本与负样本的距离，取更难的负例距离；
  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式。

计算公式与说明：令 \(a\)、\(p\)、\(n\) 分别表示 anchor、positive、negative，距离函数为 \(d(\cdot,\cdot)\)，则：

\[ \ell(a,p,n)=\max(0,d(a,p)-d(a,n)+\text{margin}) \]

只有当锚点离正样本不够近，或离负样本不够远时，损失才大于 0。默认使用 \(p=2\) 的欧氏距离。

代码逐行解释：

  1. anchor：形状 [2,2]，两个锚点样本，每个样本是 2 维嵌入向量；设置 requires_grad=True，代表其通常由待训练模型产生。
  2. positive 和 negative：形状必须与 anchor 一致。相同行组成一个三元组：positive 应与 anchor 同类，negative 应与 anchor 异类。本例将 positive 设在 anchor 附近、negative 设得很远。
  3. TripletMarginLoss(margin=0.5,p=2)：使用 \(L_2\) 欧氏距离。它并不是直接最小化正样本距离，而是要求“负距离 - 正距离”至少为 0.5。
  4. 前向调用：逐行分别计算 \(d(a,p)\)、\(d(a,n)\) 和 hinge 项，默认把两个三元组的损失平均。
  5. backward()：只有损失为正的困难三元组会产生梯度。此例已经满足约束，loss 可能为 0，梯度也为 0；这不是出错，而是 margin 已被满足。

内部计算过程：

示例数据：第一组三元组为 \(a=[0,0]\)、\(p=[0.1,0]\)、\(n=[2,2]\)，margin=0.5、\(p=2\)（欧氏距离）。

计算步骤：

  1. 计算 anchor 与正样本距离：

    \[d(a,p)=\sqrt{(0-0.1)^2+(0-0)^2}=0.1\]

  2. 计算 anchor 与负样本距离：

    \[d(a,n)=\sqrt{(0-2)^2+(0-2)^2}=\sqrt8\approx2.828\]

  3. 计算三元组损失：

    \[l_1=\max(0,0.1-2.828+0.5)=0\]

    第二组三元组也满足相同间隔，因此 \(l_2=0\)；最终平均 loss=0。

梯度含义：本例没有困难三元组，梯度为 0。若负样本改为 [0.2,0]，则损失为 \(0.4\)，反向传播会拉近 anchor/positive 并推远 negative。

HingeEmbeddingLoss

功能：对距离或相异度进行约束。目标为 1 时希望输入距离小；目标为 -1 时希望输入距离至少达到 margin。

主要参数：

  • margin：负样本（目标为 -1）要求达到的最小距离；
  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式。

计算公式与说明：设输入 \(x\) 是距离或相异度，标签 \(y\in\{-1,1\}\)，则：

\[ \ell(x,y)= \begin{cases} x, & y=1\\ \max(0,\text{margin}-x), & y=-1 \end{cases} \]

相似样本对（\(y=1\)）的距离越小越好；不相似样本对（\(y=-1\)）只要距离达到 margin，便不再产生损失。

代码逐行解释：

  1. distances：输入不是两组向量，而是已经计算好的三对样本距离或相异度，形状为 [3]。这里开启梯度只是为了观察损失怎样对距离施加优化信号。
  2. targets=[1,-1,-1]：第一个是相似对，目标 1 要求距离尽可能小；后两个是不相似对，目标 -1 要求距离至少达到 margin。
  3. HingeEmbeddingLoss(margin=1.0)：对正对直接使用距离作为损失；对负对只惩罚那些距离小于 1 的样本。默认按 3 个元素平均。
  4. backward()：相似对总会有把距离变小的驱动力；负对仅在距离不足 margin 时产生把距离增大的驱动力，达到 margin 后梯度为 0。

内部计算过程：

示例数据：distances=[0.2,1.5,0.8]，targets=[1,-1,-1]，margin=1。

计算步骤：

  1. 相似对（标签 1）：直接使用距离作为损失：

    \[l_1=0.2\]

  2. 第一个不相似对（标签 -1）：

    \[l_2=\max(0,1-1.5)=0\]

  3. 第二个不相似对（标签 -1）：

    \[l_3=\max(0,1-0.8)=0.2\]

  4. 得到最终输出：

    \[loss=(0.2+0+0.2)/3\approx0.1333\]

梯度含义：第一个距离被推动变小，第三个距离被推动变大，第二个距离已超过 margin 因而没有梯度。

CosineEmbeddingLoss

功能：根据余弦相似度约束两组向量。目标为 1 时鼓励向量方向相同；目标为 -1 时要求余弦相似度不超过 margin。

主要参数：

  • margin：负样本允许的最大余弦相似度，通常取 [0, 0.5]；
  • size_average：已废弃，请用 reduction；
  • reduce：已废弃，请用 reduction；
  • reduction：损失聚合方式。

计算公式与说明：设余弦相似度为：

\[ \cos(x_1,x_2)=\frac{x_1\cdot x_2}{\|x_1\|_2\|x_2\|_2} \]

标签 \(y=1\) 时，损失为 \(1-\cos(x_1,x_2)\)；标签 \(y=-1\) 时，损失为 \(\max(0,\cos(x_1,x_2)-\text{margin})\)。因此它主要约束向量方向，而不是向量长度。

代码逐行解释：

  1. vector1：形状 [2,2]，两行分别是两对样本中的第一个嵌入向量；它开启梯度追踪，代表模型输出的待学习表示。
  2. vector2：与 vector1 同形状，是每对的比较对象。这里未开启梯度，仅作为固定参照；真实的双塔网络中，两个分支都可以要求梯度。
  3. targets=[1,-1]：第一对标签 1 表示相似，目标是余弦相似度接近 1；第二对标签 -1 表示不相似，目标是相似度不高于 margin。
  4. CosineEmbeddingLoss(margin=0.0)：逐行计算点积除以两向量 L2 范数的乘积。margin=0 表示负对的余弦相似度只要不大于 0 就不再受惩罚。
  5. backward()：将梯度写入 vector1.grad，主要调整向量方向。余弦相似度已对长度归一化，所以它不像 L2 距离那样直接鼓励缩短向量长度。

内部计算过程：

示例数据：第一对为 \([1,0]\) 与 \([0.9,0.1]\)、标签 1；第二对为 \([1,0]\) 与 \([-1,0]\)、标签 -1；margin=0。

计算步骤：

  1. 第一对计算余弦相似度：

    \[cos=\frac{0.9}{1\times\sqrt{0.9^2+0.1^2}}\approx0.9939\]

    正对损失为 \(l_1=1-0.9939\approx0.0061\)。

  2. 第二对计算余弦相似度：

    \[cos=-1,\qquad l_2=\max(0,-1-0)=0\]

  3. 得到最终输出：

    \[loss=(0.0061+0)/2\approx0.00305\]

梯度含义：第一对仍会被轻微推动到完全同向；第二对已满足“相似度不大于 0”的负对约束，梯度为 0。

3.6.6 序列对齐：CTCLoss

CTC 用于输入序列与目标序列长度不同、且逐时间步对齐关系未知的任务，例如语音识别和手写文字识别。

CTCLoss

功能：计算连接时序分类（CTC）损失，适合输入序列和目标序列长度不同、且不知道逐时间步对齐方式的任务，例如语音识别与手写文字识别。

主要参数：

  • blank：blank 类别的索引，默认 0；目标序列中不能出现该索引；
  • reduction：'none'、'mean' 或 'sum'；
  • zero_infinity：为 True 时，将无法对齐导致的无穷损失及梯度置零，避免无穷值传播。

计算公式与说明：设模型在 \(T\) 个时间步上输出对数概率，目标标签序列为 \(y\)。CTC 会枚举所有“压缩后等于 \(y\)”的合法路径 \(\pi\)：先合并连续重复标签，再删除 blank 标签。损失是这些路径总概率的负对数：

\[ \ell_{\mathrm{CTC}}=-\log\sum_{\pi\in\mathcal{B}^{-1}(y)}\prod_{t=1}^{T}P(\pi_t\mid t) \]

其中 \(\mathcal{B}\) 表示“合并重复并删除 blank”的映射。CTC 不要求事先知道每个目标字符对应哪个时间步，但要求输入序列有足够长度容纳目标及必要的 blank/重复标签。

代码逐行解释：

  1. T, N, C = 6, 2, 5：定义输入时间步数、批量大小和类别数。类别索引 0 被保留为 blank，真正可输出的目标标签是 1 到 4；因此 targets 中不能出现 0。
  2. logits = torch.randn(T,N,C,requires_grad=True)：模拟序列模型（如 RNN/Transformer）在每个时间步为每个样本输出 5 类原始得分，形状严格为 [时间步, 批量, 类别]。注意它与很多 batch_first=True 的模型输出不同，需要留意维度顺序。
  3. log_probs = F.log_softmax(logits, dim=2)：只在类别维 C 上归一化，使每个 (t,n) 位置的类别概率和为 1，再取对数。CTCLoss 接收对数概率，用它可以将一条路径上的概率连乘转为对数域的稳定求和。
  4. targets = [1,2,3,1,2]：采用“拼接的一维目标”表示两个不等长标签序列。它不含 blank：前 2 个属于第一个样本 [1,2]，后 3 个属于第二个样本 [3,1,2]。
  5. input_lengths 与 target_lengths：前者指出两个输入都有效到第 6 个时间步；后者是 [2,3]，让 CTCLoss 能从拼接 targets 中正确切分目标。真实的变长批次中，input_lengths 常常小于最大的 T。
  6. nn.CTCLoss(blank=0, zero_infinity=True)：指定 blank 类，默认 reduction='mean'。zero_infinity=True 在输入长度无法容纳目标序列等异常对齐时把无穷损失/梯度置零，但不替代对数据长度的检查。
  7. 调用、backward() 和打印：函数用动态规划累加所有合法路径的概率，得到单个标量损失。反向传播为 [T,N,C] 的每个 logits 给出梯度，训练模型在正确时间步上增加目标字符或 blank 的概率。

内部计算过程：

示例数据：T=6、N=2、C=5；blank 类为 0。第一个目标为 [1,2]，第二个目标为 [3,1,2]。logits 是随机生成的，因此不假设其具体类别概率。

计算步骤：

  1. 每个时间步归一化：对每个 (t,n) 的 5 个 logits 执行 log_softmax，得到 \(\log P(c\mid t,n)\)；每个时间步的普通概率在类别维相加为 1。

  2. 枚举第一个目标的合法路径：例如路径 [0,1,1,0,2,0] 先合并重复项得到 [0,1,0,2,0]，再删除 blank 得到 [1,2]，因此合法；所有压缩结果不为 [1,2] 的路径不计入。

  3. 聚合路径概率：每条合法路径的概率是各时间步对应类别概率的连乘，例如：

    \[P(0\mid t_1)P(1\mid t_2)P(1\mid t_3)P(0\mid t_4)P(2\mid t_5)P(0\mid t_6)\]

    将所有合法路径相加后取负对数得到第一个样本损失；第二个目标 [3,1,2] 同样处理。

  4. 得到最终输出：默认 reduction='mean' 会先按每个目标序列长度归一化两个样本损失，再取批量平均。

梯度含义：梯度并不强制某个固定时间步输出某个标签，而是提高所有能组成正确目标的路径总概率；这正是 CTC 能处理未知对齐的原因。

3.6.7 小结：常见选择与易错点

任务 推荐损失函数 模型输出 目标格式
单标签二分类 BCEWithLogitsLoss [N] 或 [N, 1] logits 同形状的 float，值为 0/1
单标签多分类 CrossEntropyLoss [N, C] logits [N] 的 long 类别索引
多标签分类 BCEWithLogitsLoss [N, C] logits [N, C] 的 float 0/1 矩阵
连续值回归 MSELoss / L1Loss / SmoothL1Loss 连续预测值 与输出形状一致的 float
序列无对齐标注 CTCLoss [T, N, C] 对数概率 标签序列与各自长度

最常见的错误是“对 logits 重复做激活”：CrossEntropyLoss 前不要手动 softmax，BCEWithLogitsLoss 前不要手动 sigmoid。只有使用 BCELoss 时才应传入 sigmoid 后的概率。调用损失函数前，也应先检查输出形状、目标形状、目标数据类型和标签取值范围是否匹配。
